### Phase 2: Feature Engineering & Graph Construction
**File:** `notebooks/02_feature_engineering.ipynb` (38 KB, 55 cells)

#### Contents:
1. **Setup & Imports:** Data science libraries and graph tools
2. **Data Loading:** Load transactions, addresses, and labels
3. **Data Cleaning:**
   - Duplicate removal (transactions & addresses)
   - Ethereum address validation (format & checksums)
   - Missing value handling (fill with 0 for numerics, drop for labels)
4. **Graph Construction:**
   - Build directed graph using NetworkX
   - Aggregate multiple transactions between same addresses
   - Graph statistics (nodes, edges, density, connectivity)
5. **Feature Engineering:**
   - Compute 12 node features per address:
     1. in_degree
     2. out_degree
     3. total_eth_received
     4. total_eth_sent
     5. avg_tx_value_in
     6. avg_tx_value_out
     7. max_tx_value
     8. unique_in_neighbors
     9. unique_out_neighbors
     10. account_lifetime (in days)
     11. failed_tx_ratio
     12. avg_gas_used
6. **Feature Normalization:**
   - StandardScaler applied to all 12 features
   - Mean = 0, Std = 1 per feature
   - Scaler saved for test data
7. **Edge Index Preparation:**
   - Convert graph edges to PyTorch Geometric format
   - 2 x num_edges array (source & target indices)
8. **Label Preparation:**
   - Map labels to nodes (-1 for unlabeled)
   - Class distribution analysis
9. **Data Saving:**
   - Save all processed data to `data/processed/`
10. **Verification:** Load and validate all saved files

#### Features:
- Robust data validation and error handling
- Detailed statistics at each step
- Node-to-address mapping for interpretability
- Comprehensive documentation via markdown
- Multiple visualization types
- Processing report with full metadata

#### Visualizations Generated:

## Key Implementation Details

### Graph Construction
- **Type:** Directed graph (DiGraph) using NetworkX
- **Aggregation:** Multiple transactions between same addresses are summed
- **Edge Weights:** Transaction values (ETH amounts)
- **Nodes:** All unique Ethereum addresses

### Feature Computation
- **In-degree/Out-degree:** Direct graph properties
- **ETH amounts:** Aggregated from transaction data
- **Averages:** Computed per address across all transactions
- **Lifetime:** Calendar days between first and last transaction
- **Neighbors:** Unique connected addresses

### Normalization Strategy
- **Method:** StandardScaler (zero mean, unit variance)
- **Scope:** Applied per feature across all nodes
- **Handling:** Scaler saved for consistent test-time normalization
- **Missing values:** Handled before normalization

### Label Mapping
- **Labeled nodes:** Receive class label (0 or 1)
- **Unlabeled nodes:** Assigned value -1
- **Format:** Single integer per node
- **Distribution:** Tracked and reported
