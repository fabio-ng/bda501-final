================================================================================
DEPLOYMENT OPTIONS
================================================================================

Option 1: Docker Compose (Recommended for Development)
  docker-compose up -d
  # API available at http://localhost:8000
  # PostgreSQL available at localhost:5432

Option 2: Manual Deployment
  1. Install dependencies: pip install -r api/requirements.txt
  2. Configure: cp api/.env.example .env (edit as needed)
  3. Setup database: psql -U postgres -f init_db.sql
  4. Run: uvicorn api.main:app --host 0.0.0.0 --port 8000

Option 3: Cloud Deployment
  - Dockerfile ready for Cloud Run
  - Can be deployed to ECS, Kubernetes, etc.
  - Stateless design for scaling
  - Environment variables for configuration

CONFIGURATION REFERENCE
================================================================================

Key Environment Variables:
  DATABASE_URL              - PostgreSQL connection string
  INFERENCE_MODE            - "mock" or "real" for model mode
  MODEL_ARTIFACTS_DIR       - Path to model checkpoint files
  PHISHING_SCORE_THRESHOLD  - Default detection threshold (0-1)
  AUTO_ALERT_ENABLED        - Enable automatic alerting
  AUTO_ALERT_THRESHOLD      - Minimum score for auto-alert
  LOG_LEVEL                 - DEBUG, INFO, WARNING, ERROR
  DEBUG                     - true/false for debug mode
  KAFKA_ENABLED             - Enable Kafka integration
  GCS_PROJECT_ID            - GCP project for GCS access

All configuration options are documented in api/.env.example
